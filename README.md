# Exam Reviewer Hub

Static website with practice exams and reviewer PDFs (no build step).

- `index.html` - home page with buttons to each exam and reviewer
- `understanding-the-self.html` - 30 multiple choice + 10 identification
- `global-population-and-mobility.html` - 30 multiple choice + 10 identification
- `reviewers/` - reviewer PDFs

## Publish on GitHub Pages
1. Push all files to a repository (files at the repo root).
2. Repo Settings > Pages > Deploy from a branch > `main` / `/ (root)`.
3. Open `https://<username>.github.io/<repo>/`.
